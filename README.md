**Pluvia Analytics** is a modern, cross-platform rainfall analysis and visualization application designed with a dark glassmorphism UI design system. Built using **Python** and **Flet** (Flutter engine), it provides real-time metrics, interactive data filtering, predictive forecasting, live API synchronization, and report exports.

---

 ✨ Features

- **📊 Modern Glassmorphism Dashboard:** Dark mode layout (`#0B132B` theme) featuring interactive metric cards for Total, Average, Peak, and Minimum rainfall.
- **📈 Dynamic Data Visualizations:** Integrated comparison bar charts across major cities and monthly rainfall trend graphs.
- **🔍 Granular Scope Filtering:** Slice analytics instantly by specific cities or individual months.
- **🌐 Live Weather API Integration:** Synchronize live monthly precipitation data via the Open-Meteo API.
- **🤖 AI-Driven Predictive Forecasts:** Calculates trend projections for upcoming monsoon cycles.
- **📝 Interactive Data Management:** Add new rainfall entries dynamically via modal dialogs and manage records in a clean tabular format.
- **📥 One-Click CSV/PDF Report Exports:** Generate summary text reports and download formatted dataset exports.

---

🛠️ Tech Stack

- **Frontend / Framework:** [Flet](https://flet.dev/) (Flutter for Python)
- **Data Engine:** [Pandas](https://pandas.pydata.org/) & [NumPy](https://numpy.org/)
- **Visualizations:** Matplotlib / Native Flet Charts
- **External API:** Open-Meteo Weather API
