RainFall Data Analyzer

Rainfall Data Analyzer is a Python project that records rainfall values and analyzes them using basic Python operations. Total, average, maximum, minimum, summary reporting, and graphical visualization

The system processes rainfall values and provides useful information such as:
Total rainfall
Average rainfall
Maximum rainfall
Minimum rainfall
Summary of rainfall data
Graphical visualization of rainfall


 🌧️ Rainfall Data Analyzer

 📌 Project Overview

Rainfall Data Analyzer is an interactive application used to record,
analyze, and visualize rainfall data for different cities and months.

 ✨ Features

- Add rainfall data
- Calculate total rainfall
- Calculate average rainfall
- Find maximum rainfall
- Find minimum rainfall
- Monthly rainfall bar chart
- Rainfall trend chart
- City-wise rainfall comparison
- CSV file import
- CSV file export
- Delete individual records
- Clear all records
- Load sample rainfall data
- Interactive dashboard

 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Chart.js
- CSV

 📊 Data Analysis

The system automatically calculates:

- Total Rainfall
- Average Rainfall
- Maximum Rainfall
- Minimum Rainfall

 📈 Data Visualization

The dashboard provides:

1. Monthly Bar Chart
2. Rainfall Trend Chart
3. City Comparison Chart
